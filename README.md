# FORM 82

Personal home workout PWA. Includes Monday/Wednesday/Friday routines, exercise instructions, completion checkboxes, and local weight/waist history.

## Publish with GitHub Pages
1. Upload `index.html`, `manifest.json`, `sw.js`, and `icon.svg` to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main`, folder `/ (root)`, then Save.
5. Wait for the Pages URL to appear.
6. Open the URL in Safari and choose Share → Add to Home Screen. On Android, open in Chrome and choose Install app.

Progress is stored locally in the browser on each device. Cross-device sync is not included in this first version.
